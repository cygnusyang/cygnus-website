海拔为什么不准 / 为什么显示「--」

海拔有两条来源：GPS 与气压计。GPS 垂直精度本就弱于水平精度，气压高度则依赖海平面气压基准。App 把两者融合，并在数字旁恒显误差范围与来源标识（系统融合 / 已校准 / GPS 粗定位）。

当信号不足或数据源无法给出可信值时，显示「--」而不是编一个数字。这是有意为之——一个假精确的海拔比没有海拔更危险。

怎么做已知点校准

  1. 站在一个海拔已知的地点（如官方标高碑、地形图标注点、机场标高）。
  2. 打开气压详情页，进入「已知点校准」，输入该地点的真实海拔。
  3. App 反推海平面气压并保存基准。校准后来源标识会变为「已校准」。

校准不是一次性的：天气系统过境会让气压漂移，隔几天或跨地区出行后建议重新校准一次。

没有气压计的设备

部分较早的 iPhone 机型没有气压计。此时气压页会说明「无法记录气压趋势」，海拔仍可通过 GPS 提供（精度较低）。水平仪与指南针不受影响。

权限被拒绝了怎么办

  • 定位：iOS「设置 → 峰行 → 位置」改为「使用 App 期间」。用于测海拔、经纬度与真北。
  • 相机 / 照片：用于水印相机。照片只写入你的相册，App 不读取你的相册。
  • 运动与健身：用于读取气压计与高度计、指南针倾斜补偿。

任一权限被拒，其余功能照常可用；App 不会因为缺权限而停在空页面。

订阅：取消、恢复、首年免费

  • 取消：iOS「设置 → Apple ID → 订阅 → 峰行 → 取消订阅」。删除 App 不会取消订阅。
  • 恢复购买：换机或重装后在订阅页点「恢复购买」。
  • 退款：由 Apple 处理，前往 reportaproblem.apple.com。
  • 为什么没看到「首年免费」：免费试用每个 Apple ID 在同一订阅组内只能用一次。若你的账号此前用过该试用，页面会直接显示年费价格，这是 Apple 的规则，App 无法绕过。

说明：海拔、气压、指南针、水平仪永久免费，不订阅也不会失效。订阅是自愿支持，换来后续新增的仪表与主题。

切换语言后界面没变

语言在设置页选择后需要重新打开 App 生效（App 不做自杀式重启）。系统语言变化同样在下次启动时应用。

为什么没有 iPad 版

首版只发布 iPhone 版本，横屏与 iPad 多窗口布局尚未逐一验证，与其带着没测过的版式上架，不如先不声明支持。iPad 用户仍可安装 iPhone 兼容版本。
