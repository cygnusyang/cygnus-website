Principles

What these tools share.

Your work stays with you

Data lives in files you choose, not on a server we run. We do not hold it, and an agent reaches it locally — never through an account we control.

Built for AI agents

Every tool ships an MCP server, so Claude Code, Codex and CodeBuddy can read and change real state instead of only describing it.

Native macOS

SwiftUI front ends and the App Sandbox. Built for the Mac, not a web app in a wrapper.

One person, careful software.

Independent software, designed, built and documented with care. Every tool is proprietary, and all share the same starting point: an agent should act on real work, not just talk about it.
