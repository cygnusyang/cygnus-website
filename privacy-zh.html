隐私

最后更新：2026-11-10

应用不会上传你的项目文件或密码库内容。两款应用都没有账号体系、没有分析统计、没有崩溃上报、没有广告，也没有第三方 SDK。本网站是另外一回事 —— 本站收集了什么，见下方「本网站」一节。

KaidoPlan

  • 你的 .kaido 文件只存在于你放置它们的位置。应用从不上传、备份或同步项目内容。
  • 为了重新打开最近的项目，在你明确选择了文件或文件夹之后，应用会在本地偏好设置中保存一个安全作用域书签（security-scoped bookmark）。
  • MCP 服务（默认关闭）只监听 127.0.0.1，需要本地生成的 bearer 令牌，并且只能访问你授权的文件夹。

Bitcoffer

  • 密码、密钥与凭据只存储在你设备上的加密密码库中，没有云同步。
  • 唯一的网络例外是更新检查（OTA）：从 GitHub Releases 获取一份签名清单。Rust 核心不含任何网络库；这一说法由测试保证。
  • MCP 服务把密钥放进子进程的环境变量，而不把密钥值回传给模型。

本网站

以上各节描述的是应用本身。本网站是独立的，有自己的规则：

  • 托管日志：本网站由 GitHub Pages（GitHub, Inc.）提供服务，它保留标准请求日志——IP 地址、User-Agent——用于安全与防滥用。我们不会据此建立用户画像。
  • 结账：KaidoPlan 的产品站点会加载 Paddle.js，为 KaidoPlan Pro 直购打开结账。Paddle 可能设置维持结账会话所必需的少量 cookie；本网站自身不设置任何 cookie。Bitcoffer 没有站点端结账。

购买

对于 KaidoPlan 直购，支付由作为记录商户（Merchant of Record）的 Paddle.com Market Ltd 处理。Paddle 处理你的支付信息，我们始终看不到你的卡号。Bitcoffer 目前没有站点端结账；购买与授权咨询请发邮件至 ruohuyang@163.com。
