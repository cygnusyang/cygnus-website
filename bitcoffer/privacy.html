Bitcoffer 隐私政策

最后更新：2026-10-25 · 完整条款与适用范围以仓库中的 PRIVACY.md 为准

一句话：Bitcoffer 不收集任何数据。没有账号、没有遥测、没有云同步、没有第三方 SDK。你的密码库只存在于你的 Mac 上，用你的主密码加密。唯一的网络访问，是你在点「检查更新」时向 GitHub 的四个固定域名发一个 HTTP 请求。

1 · 我们不做什么

不做说明
没有账号产品里没有注册、没有邮箱、没有用户 ID
没有遥测没有分析 SDK、没有崩溃上报、没有使用计数、没有「匿名」打点
没有云同步密码库是一个本地文件，Bitcoffer 从不上传它
没有广告与追踪没有需要你关闭的开关，因为什么都没有收集
没有第三方网络 SDK不链接广告、分析、字体或 CDN 框架

2 · 什么留在你的 Mac 上

数据位置保护
密码库（条目、TOTP 密钥、通行密钥元数据）~/Library/Containers/top.cygnusyang.coffer/Data/Documents/Bitcoffer/<vault-uuid>/Argon2id 派生密钥 + AEAD；主密码从不存储
诊断日志~/Library/Containers/top.cygnusyang.coffer/Data/Library/Logs/Bitcoffer-diag.log本地纯文本，从不自动上传
剪贴板macOS 剪贴板，仅在你复制字段时写入可选：按你设定的超时自动清空
偏好设置应用容器内的 UserDefaults语言、锁屏超时等

除非你主动导出或复制，否则这些内容不会离开这台机器。

3 · 唯一的网络访问：检查更新

Bitcoffer 只在你明确要求检查更新时才发起网络请求。没有后台轮询。

项目内容
白名单域名api.github.com、github.com、objects.githubusercontent.com、release-assets.githubusercontent.com
发送什么对 …/releases/latest/download/update-manifest.json 的标准 HTTPS GET，加上系统 URL session 的默认请求头（如 User-Agent）。不含密码库数据、不含标识符、除请求路径外不含版本指纹。
收到什么签名清单（Ed25519）与下载地址；在信任任何内容之前，先用内置于 App 的公钥校验签名
下载Bitcoffer-vX.Y.Z.zip，来自同一白名单；SHA-256 与签名清单比对

检查更新失败时，App 照常离线可用，只会把错误报给你。

4 · AI 工具 / MCP 集成（需你手动开启）

  • MCP 服务走 stdio 或 Unix domain socket（$BITCOFFER_MCP_UDS），从不走 TCP，从不监听公网端口。
  • 工具默认只读：AI 客户端可以列条目名称与元数据；经你批准后，才能在把密钥注入该子进程环境的前提下执行命令。
  • 密钥值从不回传到模型上下文——没有任何一个工具会打印密码。
  • 向 Claude Code / CodeBuddy / Codex 注册时只写本地配置文件，不向我们发送任何内容。
  • 你若不开启，就没有任何 MCP 进程在跑。

5 · 诊断

  • 日志写在本地并在磁盘上轮转，不会自行离开这台机器。
  • 提交问题时你可以手动附上相关日志——请先自己看一遍。日志按设计规则（R2）不含密码值，但会含时间戳、错误码与文件路径。
  • 没有自动崩溃上报。App 崩溃时 macOS 可能在 ~/Library/Logs/DiagnosticReports/ 生成报告，那份文件属于你，只有你选择分享时才会外流。

6 · 删除你的数据

操作效果
删除条目移入库内回收站，可恢复或彻底删除
删除密码库移除库目录；没有加密备份则不可恢复
删除 App移除二进制；库目录仍然保留，除非你自己删除
彻底清除删除 App 以及 ~/Library/Containers/top.cygnusyang.coffer/

7 · 儿童与法律

Bitcoffer 完全不收集个人数据，因此也不收集未成年人的数据。它是一个本地工具，不是在线服务：没有账号关系，也没有需要签署的数据处理协议。

8 · 自己验证这些说法

信任不该需要你相信一份 markdown 文件：

  1. 权限声明 —— 构建出的 App 声明 App Sandbox 与恰好一条网络权限： 
    codesign -d --entitlements - /Applications/Bitcoffer.app
    应当只看到 com.apple.security.app-sandbox 与 com.apple.security.network.client，再无其他 network.* 键。
  2. 盯着流量 —— 用 Little Snitch / LuLu / nettop 观察，或者干脆断网：除检查更新外，其余功能照常工作。
  3. 读源码 —— 网络代码只存在于更新模块 macos/Bitcoffer/Updater/，搜索 URLSession 即可枚举全部调用点。
  4. 看日志 —— ~/Library/Containers/top.cygnusyang.coffer/Data/Library/Logs/Bitcoffer-diag.log 是纯文本，直接读。

9 · 政策变更

任何数据处理上的变化都会记录在 CHANGELOG.md 与本文件的 git 历史里。Bitcoffer 没有服务端，因此我们无法在不发布新版本的情况下改变你数据的去向——而每个版本都是签名、可检查的产物。

11 · 官网访问统计

Bitcoffer 官网记录页面访问、下载按钮点击、来源标识、页面语言及国家代码，用来了解哪些入口带来下载。浏览器仅在当前会话保存来源标识。服务端用按天变化的 IP 哈希限流，访问统计事件保留 90 天。密码库内容不会进入官网统计。

Bitcoffer’s website records page views, download clicks, referral tags, page language and country codes. The browser keeps referral tags for the current session. The server uses a daily IP hash for rate limiting and retains analytics events for 90 days. Website analytics receive no vault contents.

English summary — Bitcoffer collects nothing: no account, no telemetry, no analytics, no cloud sync, no third-party SDKs. Your vault exists only on your Mac, encrypted with your master password. The only network access happens when you click “Check for Updates”, and it goes to four fixed GitHub hosts. See the full PRIVACY.md for details and verification steps.
