Privacy

Last updated: 10 November 2026

The apps do not upload your project files or vault contents. Neither app has an account system, analytics, crash reporting, advertising, or a third-party SDK. This website is separate — see "This website" below for what this site collects.

KaidoPlan

  • Your .kaido files live only where you put them. The app never uploads, backs up, or syncs project content.
  • To reopen a recent project, the app stores a security-scoped bookmark in your local preferences after you explicitly choose a file or folder.
  • The MCP server (off by default) listens on 127.0.0.1 only, requires a locally generated bearer token, and can only reach folders you authorize.

Bitcoffer

  • Passwords, keys, and credentials are stored in an encrypted vault on your device only. No cloud sync.
  • The single network exception is the update check (OTA), which fetches a signed manifest from GitHub Releases. The Rust core ships no networking crates; this claim is asserted by tests.
  • The MCP server hands secrets to a child process's environment without returning the values to the model.

This website

The sections above describe the apps. This site is separate and has its own rules:

  • Hosting logs: the site is served by GitHub Pages (GitHub, Inc.). It keeps standard request logs — IP address, user agent — for security and abuse prevention. We do not build profiles from them.
  • Checkout: KaidoPlan's product site loads Paddle.js to open checkout for KaidoPlan Pro direct-download purchases. Paddle may set the minimal cookies needed to keep a checkout session; this site sets none of its own. Bitcoffer has no site checkout.

Purchases

For KaidoPlan direct-download purchases, payment is handled by Paddle.com Market Ltd as Merchant of Record. Paddle processes your payment details; we never see your card number. Bitcoffer currently has no site checkout; purchase and licensing inquiries go to ruohuyang@163.com.
