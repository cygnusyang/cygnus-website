About these tools

Built independently by cygnusyang

A set of macOS tools along one line: from words to work. Two today, more to come.

What we make

Both current tools are native macOS and ship an MCP server, so an agent can act on real work instead of only describing it:

  • KaidoPlan — a project-planning workbench for AI coding agents;
  • Bitcoffer — a local-first password and secret manager.

How we work

  • Proprietary: the source is closed; commercial licences fund ongoing development. Your data still never leaves your machine.
  • Data stays local: no accounts, no cloud sync, no telemetry.
  • Documentation first: design docs and acceptance criteria are written before code. Where they can be published, they ship in the repo.

Contact

For product issues, open an issue on github.com/cygnusyang/KaidoPlan/issues (KaidoPlan) or github.com/cygnusyang/bitcoffer-releases/issues (Bitcoffer). For sales and licensing, email ruohuyang@163.com.
