关于这些工具

由 cygnusyang 独立开发

这是一组围绕「本地优先、面向 AI」这条线做的 macOS 工具。目前有两件，后面还会继续增加。

做什么

目前的两件工具，都是 macOS 原生、数据不出本机、并带 MCP 服务接入 AI 编码工具：

  • Kaido Plan —— 面向 AI 编码智能体的项目规划工作台；
  • Bitcoffer —— 本地优先的密码与密钥管理器。

怎么做的

  • 源码公开：每件工具的源码都可在 GitHub 上查阅，你能确切知道跑在机器上的是什么。
  • 数据不出本机：没有账号系统、没有云同步、没有遥测。
  • 文档先行：每个版本的设计文档与验收判据都随仓库公开。

联系方式

产品问题请在对应仓库的 Issues 提出；销售与许可问题发邮件到 ruohuyang@163.com。

About these tools

Built independently by cygnusyang

A set of macOS tools along one line: local-first, AI-ready. Two today, more to come.

What we make

Both current tools are native macOS, local-first, and ship an MCP server for AI coding tools:

  • Kaido Plan — a project-planning workbench for AI coding agents;
  • Bitcoffer — a local-first password and secret manager.

How we work

  • Source available: every tool is on GitHub, so you can read exactly what runs on your machine.
  • Data stays local: no accounts, no cloud sync, no telemetry.
  • Documentation first: every version ships with design docs and acceptance criteria in the repo.

Contact

For product issues, open an issue on the relevant repository. For sales and licensing, email ruohuyang@163.com.
