About these tools

Built independently by cygnusyang

A set of macOS tools along one line: local-first, AI-ready. Two today, more to come.

What we make

Both current tools are native macOS, local-first, and ship an MCP server for AI coding tools:

  • Kaido Plan — a project-planning workbench for AI coding agents;
  • Bitcoffer — a local-first password and secret manager.

How we work

  • Proprietary: the source is closed; commercial licences fund ongoing development. Your data still never leaves your machine.
  • Data stays local: no accounts, no cloud sync, no telemetry.
  • Documentation first: every version ships with design docs and acceptance criteria in the repo.
