Quickstart

Run your first KaidoPlan schedule on macOS

Open a public release plan and calculate its schedule, critical path and deadline conflicts.

Download KaidoPlan for macOS Download the demo plan

Install and open the sample

Download KaidoPlan for macOS from GitHub Releases. If you want the CLI walkthrough, install the separate CLI formula below. Download the public sample into your working directory. It contains 11 fictional release tasks and a deliberately tight deadline. It is safe to inspect and edit a copy.

brew install cygnusyang/kaidoplan/kaidoplan-cli
kaidoplan project summary --file release-demo.kaido --lang en
kaidoplan schedule compute --file release-demo.kaido --lang en
kaidoplan violations --file release-demo.kaido --lang en

Check your result

The summary should show 11 tasks. The schedule lists start and finish dates for the release tasks. The violation report should flag Publish release: its predecessors do not fit the existing finish constraint. Use the report to identify the cause before changing any dates.

Continue in the app

Open the same file in KaidoPlan to see the task list and Gantt chart. For your own project, start with a few delivery tasks, connect the dependencies you know, and add constraints only for commitments that must hold. Rerun the check after changing the plan.
